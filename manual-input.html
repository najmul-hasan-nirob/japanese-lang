Manual Input

Add a new Similar Words entry without editing the JavaScript file manually.

Select an existing group, or choose Create a new group to add one.
This currently has one option. More data sets can be added here later.
The token is kept only in this browser tab for the current session. It is not saved in the repository or localStorage.
